## 0. 极简版：10 分钟从零到第一个模型

> **如果你只想尽快上手，跟这条路线走就行。看不懂的术语不用管，后面章节有详细解释。**

### 0.1 一次性安装（5 分钟，只做一次）

**Windows 用户：**

```bash
# 1. 下载项目（任选一种）
git clone https://github.com/267351/VisionCore.git
cd VisionCore

# 2. 创建虚拟环境 + 安装依赖（复制下面三行，回车，等它跑完）
python -m venv .venv
.venv\Scripts\activate
pip install ultralytics opencv-python pyyaml onnx onnxruntime

# 3. 验证
python -c "from ultralytics import YOLO; print('OK')"
```

**Linux 用户：**

```bash
# 1. 下载项目
git clone https://github.com/267351/VisionCore.git
cd VisionCore

# 2. 创建虚拟环境 + 安装依赖
python3 -m venv .venv
source .venv/bin/activate
pip install ultralytics opencv-python pyyaml onnx onnxruntime

# 3. 验证
python -c "from ultralytics import YOLO; print('OK')"
```

看到 `OK` 就装好了。

### 0.3 训你自己的模型（4 分钟操作 + 训练时间另计）

一共就 **4 步**：

```
① 拍照片 → ② 标照片 → ③ 写配置 → ④ 跑命令
```

---

**① 拍照片**

用手机拍。每种物体 50-100 张，不同角度、不同光线、不同背景。JPG 格式。

---

**② 标照片（用 LabelImg）**

```bash
pip install labelImg
labelImg
```

- 打开后点 `Open Dir` 选图片文件夹
- 左侧格式选 **`YOLO`**（不是 PascalVOC！）
- 按 `W` 画框 → 输入类别名 → 回车
- 按 `D` 下一张
- 标完关掉就行

---

**③ 写配置**

在 `configs/tasks/` 下新建一个文件，比如 `my_first.yaml`：

```yaml
task:
  name: "my_first"
  type: "detect"
  description: "我的第一个模型"

data:
  path: "data/my_first/"
  train: "images/train"
  val: "images/val"
  nc: 2                          # ← 改成你的类别数
  names:
    - 类别一                      # ← 改成你的类别名
    - 类别二

train:
  epochs: 100
```

---

**④ 跑命令**

```bash
python scripts/train.py --task my_first
```

等它跑完。看到 `训练完成!` 就拿到模型了。

```bash
# 用模型识别新图片
python scripts/infer.py --task my_first --source 你的图片.jpg
```

## 3. 环境安装——详细版

> 如果你已经按极简版装好了，跳过这节直接看第4节。

### 3.1 安装 Python

**Windows：**
1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击黄色大按钮下载最新版（Python 3.12 或 3.13 都行）
3. 运行下载的安装程序
4. **重要！** 勾选底部的 `Add Python to PATH`（把Python加入系统路径）
5. 点击 `Install Now`
6. 安装完成后，打开命令提示符（按 Win+R，输入 `cmd`，回车）
7. 输入 `python --version`，如果显示 `Python 3.x.x` 就成功了

**Linux：**
```bash
# Ubuntu/Debian
sudo apt update && sudo apt install python3 python3-pip python3-venv -y
```

### 3.2 下载项目

```bash
# 方式一：用 Git 克隆（推荐）
git clone git@github.com:267351/VisionCore.git
# 或者从 Gitee:
git clone git@gitee.com:hong--yingsong/vision-core.git

# 方式二：直接下载 ZIP 解压
# GitHub: https://github.com/267351/VisionCore/archive/refs/heads/main.zip
# Gitee: https://gitee.com/hong--yingsong/vision-core/repository/archive/main.zip

cd VisionCore
```

> **注意：** 之后所有命令都在 `VisionCore` 目录下执行！

### 3.3 创建虚拟环境

> **什么是虚拟环境？** 就是给这个项目一个"独立房间"，它的 Python 包不会和别的项目打架。

**Windows（cmd）：**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux：**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

命令行前面出现 `(.venv)` 就说明激活成功了。

> **每次开新命令行窗口都要重新激活一次！**

### 3.4 安装依赖

```bash
pip install ultralytics opencv-python pyyaml onnx onnxruntime pytest
```

等待安装完成（5-10分钟），看到 `Successfully installed ...` 就是成功了。

### 3.5 验证

```bash
python -c "from ultralytics import YOLO; print('环境安装成功！')"
```

## 5. 训练你自己的识别模型——详细版

整个过程分 6 步：

```
拍照片 → 标照片 → 放文件 → 写配置 → 训练 → 用模型
```

### 5.1 第一步：拍照片

**拍照要点：**
- 用手机或相机拍即可，不需要专业设备
- 多角度拍摄（正面、侧面、斜上方）
- 不同光照（自然光、车间灯、手电筒）
- 不同背景（工作台、产线、户外）
- 每种物体至少拍 50-100 张（越多越好，建议 200 张以上）
- 图片格式：JPG 或 PNG

**文件命名建议：**
```
IMG_0001.jpg, IMG_0002.jpg, IMG_0003.jpg, ...
```

**以"焊条型号识别"为例，你需要拍：**
- E6013 焊条的照片（50-100张）
- E7018 焊条的照片（50-100张）
- 309L 不锈钢焊条的照片（50-100张）
- ER5356 铝焊条的照片（50-100张）
- ER70S-6 焊条的照片（50-100张）

### 5.2 第二步：标照片

使用标注工具在图片上画出物体位置，并标记类别。

**推荐工具（免费）：**

| 工具 | 适合人群 | 平台 |
|------|---------|------|
| **LabelImg** | 桌面软件，简单直接 | Windows/Mac/Linux |
| **Roboflow** | 网页版，功能丰富 | 浏览器 |
| **Make Sense** | 网页版，无需注册 | 浏览器 |

**LabelImg 使用步骤（推荐新手用这个）：**

1. 安装并启动：
   ```bash
   pip install labelImg
   labelImg
   ```

2. 点击左侧 `Open Dir`，选择你的图片文件夹
3. 点击左侧 `Change Save Dir`，选择标注文件保存的文件夹
4. 确认左侧格式选择为 **`YOLO`**（不是 PascalVOC！）
5. 按 `W` 键，鼠标变成十字，在图片上拖拽画框
6. 松开鼠标后输入类别名（如 `E6013`），点 OK
7. 按 `D` 键跳到下一张图片
8. 重复 5-7，标完所有图片

**快捷键：**
- `W` — 开始画框
- `D` — 下一张
- `A` — 上一张
- `Ctrl+S` — 保存
- `Del` — 删除当前框

### 5.3 第三步：组织文件

标注完成后，按以下结构组织你的文件：

```
VisionCore/
└── data/
    └── rod_type/                    # 你的任务名
        ├── images/
        │   ├── train/               # 训练图片（80%的图片放这里）
        │   │   ├── IMG_0001.jpg
        │   │   ├── IMG_0002.jpg
        │   │   └── ...
        │   └── val/                 # 验证图片（20%的图片放这里）
        │       ├── IMG_0051.jpg
        │       ├── IMG_0052.jpg
        │       └── ...
        └── labels/
            ├── train/               # 训练标注文件
            │   ├── IMG_0001.txt     # 与图片同名的txt
            │   ├── IMG_0002.txt
            │   └── ...
            └── val/                 # 验证标注文件
                ├── IMG_0051.txt
                ├── IMG_0052.txt
                └── ...
```

> **训练集 vs 验证集：**
> - 训练集（80%）：用来教模型识别
> - 验证集（20%）：用来检查模型学得好不好
> - 两个集合的图片**不能重复**
>
> **什么是标注文件？** 是一个 .txt 文件，记录图片中物体位置和类别。每行格式：
> `类别编号 X中心 Y中心 宽度 高度` （全是 0-1 之间的小数）
> LabelImg 会自动生成，你不需要手写。

### 5.4 第四步：写配置文件

在 `configs/tasks/` 下新建一个 `.yaml` 文件。

**示例：`configs/tasks/my_task.yaml`**

```yaml
task:
  name: "my_task"                    # 任务名，要和 data/ 下的文件夹名一致
  type: "detect"                     # detect=目标检测(找位置), classify=分类(只判断是什么)
  description: "我的第一个识别任务"

data:
  path: "data/my_task/"              # 数据集路径
  train: "images/train"              # 训练图片子目录
  val: "images/val"                  # 验证图片子目录
  nc: 5                              # 类别数量
  names:                             # 类别名称列表
    - 类别A
    - 类别B
    - 类别C
    - 类别D
    - 类别E

train:
  epochs: 100                        # 训练100轮
  imgsz: 640                         # 图片尺寸
```

> **已有参考配置：**
> - `configs/tasks/weld_defect.yaml` — 目标检测任务示例
> - `configs/tasks/rod_type.yaml` — 分类任务示例
> - `configs/tasks/rod_state.yaml` — 另一个检测任务示例

### 5.5 第五步：开始训练

```bash
# 确保虚拟环境已激活！
# Windows: .venv\Scripts\activate
# Linux:   source .venv/bin/activate

# 开始训练
python scripts/train.py --task my_task

# 如果想用更大的模型（更准确但更慢）：
python scripts/train.py --task my_task --model-size m    # m=medium

# 如果显存不够，减小批次：
python scripts/train.py --task my_task --batch 8

# 如果没有GPU：
python scripts/train.py --task my_task --device -1
```

**训练中你会看到：**
- 进度条显示训练进度
- 每个 epoch 结束后显示损失值
- 训练完成后显示 mAP（精度指标）

> **mAP 是什么？** 简单理解就是模型的"考试分数"：
> - 0.5 以上 = 及格，基本能用
> - 0.7 以上 = 良好，大部分场景OK
> - 0.9 以上 = 优秀，接近专业水准

### 5.6 第六步：使用你的模型

训练完成后，模型保存在 `models/my_task/train/weights/best.pt`。

```bash
# 识别单张图片
python scripts/infer.py --task my_task --source 你的图片.jpg

# 识别整个文件夹
python scripts/infer.py --task my_task --source ./测试图片文件夹/

# 调高置信度阈值（减少误检）
python scripts/infer.py --task my_task --source 图片.jpg --conf 0.5

# 导出ONNX格式（给C#程序用）
python scripts/export.py --task my_task
```

## 6. 常用命令速查表

### 训练相关

```bash
# 基础训练
python scripts/train.py --task 任务名

# 用中等模型（更准）
python scripts/train.py --task 任务名 --model-size m

# 用大模型（最准，需要大显存）
python scripts/train.py --task 任务名 --model-size l

# 指定训练轮数
python scripts/train.py --task 任务名 --epochs 200

# 用CPU训练（慢）
python scripts/train.py --task 任务名 --device -1

# 减少批次大小（显存不够时）
python scripts/train.py --task 任务名 --batch 8

# 从中断处恢复训练
python scripts/train.py --task 任务名 --resume

# 指定图片尺寸（缺陷检测用大尺寸）
python scripts/train.py --task 任务名 --imgsz 1280
```

### 评估与推理

```bash
# 评估模型精度
python scripts/eval.py --task 任务名

# 识别单张图片
python scripts/infer.py --task 任务名 --source 图片.jpg

# 识别整个文件夹
python scripts/infer.py --task 任务名 --source ./文件夹/

# 调高置信度（减少误检）
python scripts/infer.py --task 任务名 --source 图片.jpg --conf 0.6

# 指定输出目录
python scripts/infer.py --task 任务名 --source 图片.jpg --output ./结果/
```

### 导出部署

```bash
# 导出ONNX（默认）
python scripts/export.py --task 任务名

# 导出FP16量化（体积减半）
python scripts/export.py --task 任务名 --half
```

## 7. 常见问题排查

### 问题1：`ModuleNotFoundError: No module named 'ultralytics'`

**原因：** 依赖没安装或虚拟环境没激活。

**解决：**
```bash
# 先确认虚拟环境已激活（命令行前面有 (.venv)）
# 如果没有，先激活：
# Windows: .venv\Scripts\activate
# Linux:   source .venv/bin/activate

# 然后重新安装
pip install ultralytics opencv-python pyyaml onnx onnxruntime pytest
```

### 问题2：`CUDA out of memory`（显存不足）

**原因：** 模型太大或批次太大，显存放不下。

**解决：**
```bash
# 方法1：减小批次
python scripts/train.py --task 任务名 --batch 8

# 方法2：用小模型
python scripts/train.py --task 任务名 --model-size n

# 方法3：减小图片尺寸
python scripts/train.py --task 任务名 --imgsz 320

# 方法4：用CPU（最慢但能跑）
python scripts/train.py --task 任务名 --device -1
```

### 问题3：`FileNotFoundError: 任务配置文件不存在`

**原因：** `--task` 后面写的名字在 `configs/tasks/` 下找不到对应的 `.yaml` 文件。

**解决：**
```bash
# 查看有哪些可用的任务配置
dir configs\tasks\        # Windows
ls configs/tasks/         # Linux

# 确认你写的名字和文件名一致（不含 .yaml 后缀）
```

### 问题4：训练时提示找不到图片

**原因：** `data/任务名/images/train/` 目录不存在或为空。

**解决：**
```bash
# 确认目录结构正确
ls data/任务名/images/train/    # 应该有图片文件
ls data/任务名/labels/train/    # 应该有对应的txt标注文件

# 确认配置文件中的路径正确
# 打开 configs/tasks/任务名.yaml，检查 data.path 是否正确
```

### 问题5：标注后训练没效果，mAP 很低

**可能原因和解决：**
- 图片太少 → 每类至少 50 张，建议 200 张以上
- 标注不对 → 检查标注框是否准确，类别名是否拼写一致
- 图片太单一 → 增加不同角度、光照、背景的图片
- 训练轮数不够 → 增加到 150-300 轮试试

### 问题6：下载模型卡住/失败

**原因：** GitHub 或 ultralytics.com 访问慢。

**解决：**
```bash
# 手动下载
python -c "
from ultralytics.utils.downloads import download
download('https://ultralytics.com/assets/yolov8n.pt', dir='.')
"

# 或者换 HuggingFace
pip install huggingface_hub
python -c "
from huggingface_hub import hf_hub_download
hf_hub_download('Ultralytics/YOLOv8', 'yolov8n.pt', local_dir='.')
"
```

### 问题7：如何知道训练完了？

训练日志最后会出现：
```
03:12:47 [INFO] 训练完成!
03:12:47 [INFO] 最佳模型: models/任务名/train/weights/best.pt
03:12:47 [INFO] mAP50: 0.8885
```

看到 `训练完成!` 就说明训完了。

## 8. 如何把模型用在 C# 程序中

训练好的模型导出为 ONNX 后，可以用 C# 直接调用。

### 8.1 准备工作

1. 安装 .NET 8.0 SDK：https://dotnet.microsoft.com/download
2. 打开 `deploy/VisionCore.Runtime/` 目录
3. 运行 `dotnet restore` 安装 NuGet 包

### 8.2 使用示例

```csharp
using VisionCore.Runtime;

// 1. 加载模型（参数：模型路径, 类别名, 是否用GPU, 输入尺寸）
var classNames = new[] { "E6013", "E7018", "309L", "ER5356", "ER70S6" };
using var inferencer = new Inferencer(
    modelPath: "models/rod_type/exports/best.onnx",
    classNames: classNames,
    useCuda: false,      // true=GPU加速
    inputSize: 640
);

// 2. 识别图片
var results = inferencer.Detect("焊条照片.jpg");

// 3. 处理结果
foreach (var r in results)
{
    if (r.Confidence > 0.5)  // 只保留置信度>50%的结果
    {
        Console.WriteLine($"检测到: {r.ClassName}，置信度: {r.Confidence:P1}");
        Console.WriteLine($"位置: x={r.X}, y={r.Y}, 宽={r.Width}, 高={r.Height}");

        // 转换为像素坐标
        var (x1, y1, x2, y2) = r.ToPixel(imageWidth: 1920, imageHeight: 1080);
        Console.WriteLine($"像素位置: 左上({x1},{y1}) 右下({x2},{y2})");
    }
}
```

### 8.3 在你的项目中引用

在你的 `.csproj` 中添加：

```xml
<ItemGroup>
    <ProjectReference Include="..\VisionCore\deploy\VisionCore.Runtime\VisionCore.Runtime.csproj" />
</ItemGroup>
```

或者直接把 `Inferencer.cs` 和 `DetectionResult.cs` 复制到你的项目中。

## 附录：全局默认参数说明

`configs/default.yaml` 中每个参数的含义：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `model.size` | `"n"` | 模型大小：n(最快)/s/m/l/x(最准) |
| `model.pretrained` | `true` | 是否用预训练权重（强烈建议true） |
| `train.epochs` | `100` | 训练轮数，数据少就多训几轮 |
| `train.batch` | `16` | 每批处理的图片数，显存不够就减小 |
| `train.imgsz` | `640` | 输入图片尺寸，检测小目标可调大到1280 |
| `train.device` | `0` | GPU编号，-1=CPU，0=第一块GPU |
| `train.workers` | `8` | 数据加载线程数 |
| `train.lr0` | `0.01` | 初始学习率 |
| `train.patience` | `50` | 50轮没提升就早停 |

> **修改默认参数：** 直接编辑 `configs/default.yaml` 即可全局生效。
> **只改某个任务：** 编辑对应 `configs/tasks/任务名.yaml` 中的 `train:` 部分。
